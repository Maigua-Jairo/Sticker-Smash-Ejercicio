# Paleta EPN de la Calculadora de Supletorio

Fuente: página de estilos de desarrollo de la EPN (https://demostemas.epn.edu.ec/estilosdesarrollo/colores.php). No está identificada como manual de identidad oficial: confirmar antes de presentarla como tal.[cite: 7]

## Roles (fondo, texto y contraste)
- Encabezado y barra superior: fondo #001f3f, texto #ffffff (16.56:1).[cite: 7]
- Botón primario: fondo #357ca5, texto #ffffff (4.59:1).[cite: 7]
- Acción destructiva (eliminar) y estado Reprobado: fondo #d33724, texto #ffffff (4.84:1).[cite: 7]
- Estado Supletorio: fondo #f7bf65, texto #111111 (11.33:1).[cite: 7]
- Estado Aprobado: fondo #5ac594, texto #111111 (8.86:1).[cite: 7]
- Fondo de pantalla: #e2e4e9 con texto #111111 (14.84:1).[cite: 7]
- Tarjetas y campos: fondo #ffffff, texto #111111 (18.88:1).[cite: 7]
- Texto secundario sobre blanco: #5a6e82 (5.27:1). No usarlo sobre #e2e4e9 (4.14:1).[cite: 7]
- Bordes e inactivos: #b5bbc8. Nunca como color de texto.[cite: 7]

## Prohibido (no cumplen 4.5:1 con texto normal)
- Blanco sobre #3c8dbc (3.67:1), #008d4c (4.27:1) o #db8b0b (2.72:1).[cite: 7]

## Reglas
- El estado se comunica siempre con texto ("Aprobado", "Supletorio", "Reprobado"), además del color.[cite: 7]
- Usa solo colores de esta lista. Si falta uno, pregunta.[cite: 7]
